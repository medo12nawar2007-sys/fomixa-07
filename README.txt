The website itself is animated: smooth reveal on scroll, hero motion, parallax, hover/3D card movement, animated background, sticky header transitions, and preview modal.

Bulk import:
Open admin.html and click the folder picker. Select one folder containing subfolders such as:
FOMIXA WORK/
  Social Media/
  Covers/
  Advertising/
The manager imports the files in one action and guesses the category from the folder name.

This prototype stores portfolio data locally in the browser. A production hosted version should connect this admin panel to persistent storage/backend.
